# 🏠 Airbnb Clone

A full-stack web application inspired by Airbnb, developed to understand and implement real-world web development concepts.

## 🚀 Features

- User authentication and authorization
- Create, edit, and delete property listings
- Browse available properties
- View detailed property information
- Image upload for listings
- Reviews and ratings
- Location-based listing information
- Responsive user interface
- Server-side form validation
- MongoDB database integration

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript, EJS, Bootstrap
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Authentication:** Passport.js
- **Templating:** EJS
- **Version Control:** Git & GitHub

## 📌 Purpose

This project was built as a practical full-stack development project to understand RESTful APIs, CRUD operations, authentication, database relationships, MVC architecture, and deployment workflows.
